# Docker Strategy v1

Status: Draft

## Goal

Provide a standardized container platform for all AkpinarLabs services.

## Principles

- One Service, One Container
- Infrastructure as Code
- Docker Compose First
- Easy Backup
- Easy Migration
- Version Controlled

## Planned Services

- Nginx Proxy Manager
- PostgreSQL
- Redis
- MinIO
- Ollama
- Open WebUI
- Uptime Kuma
- Grafana
- Prometheus
- Loki

---

Docker will be the standard application runtime of the AkpinarLabs Platform.
